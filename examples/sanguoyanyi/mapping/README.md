# Mapping data — Romance of the Three Kingdoms (ch. 1–10)

`nodes.csv` contains the node-level annotations for chapters 1–10 of *Romance of the Three Kingdoms* (《三国演义》, public domain).

- Column format follows `examples/hongloumeng/mapping/nodes.csv`: `chapter,title,coordinate,code`.
- One node per chapter; coordinates follow the 9-dimension rubric in `docs/mapping-guide.md`
  (order `T1 T2 T3 S1 S2 S3 C1 C2 C3`, ternary, code = weighted sum, universe size 3⁹ = 19683).
- `fingerprint.json` / `blueprint.json` are generated by `tri9cog fingerprint` / `tri9cog blueprint`
  (`--strategy isomorphic --nodes 10`) and verified self-consistent (10/10 matched, mean Hamming 0).
- Full text (public domain, QQ 阅读 source, 44,127 chars) lives in `../text/`.

Used as the **historical-romance control** in the inter-text discrimination study; see
`docs/control-experiment.md`.
