# Mapping data — One Hundred Years of Solitude (ch. 1)

`nodes.csv` contains the node-level annotations for chapter 1 of *One Hundred Years of Solitude*
(《百年孤独》, Gabriel García Márquez, trans. Fan Ye 范晔, Nanhai 2017).

## Copyright notice — important

- The **original Chinese translation text is under copyright**. It was used **locally only** for annotation
  purposes and is **NOT included in this repository**. No portion of the translated text is committed.
- Only the **abstract 9-dimension coordinates** (ternary, per-node), scene titles (short descriptive labels,
  not quotations) and aggregate statistics are stored here. These are facts of the annotation, not expressive copies.
- Scene titles are neutral descriptive summaries (e.g. "scene 12 冰块"), not verbatim quotations.

## Format / provenance

- Column format follows `examples/hongloumeng/mapping/nodes.csv`: `chapter,title,coordinate,code`.
- **12 scene nodes** split on scene change (per Step 1 of `docs/mapping-guide.md`); coordinates follow the
  9-dimension rubric (order `T1 T2 T3 S1 S2 S3 C1 C2 C3`, ternary, code = weighted sum, universe 3⁹ = 19683).
- `fingerprint.json` / `blueprint.json` are generated by `tri9cog fingerprint` / `tri9cog blueprint`
  (`--strategy isomorphic --nodes 12`) and verified self-consistent (12/12 matched, mean Hamming 0).
- Source text located via public web reproduction of the Fan Ye translation; annotation done locally from the
  excerpt (9,836 chars), used for this experiment only.

Used as the **modernist/translated control** (cross-language, cross-century, magic-realist) in the
inter-text discrimination study; see `docs/control-experiment.md`.
