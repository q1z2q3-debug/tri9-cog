# 三元九维 19683 解析规则框架（v1.0）

用于对任意小说执行「映射 → 分析 → 再创作」的统一坐标系。规则已形式化，可逐条套用、可计算、可复现。

## 一、体系总览

- **三元**：时间（T）、空间（S）、因果（C）——观察小说的三个根本视角。
- **九维**：每元拆出三个维度，共 9 维。
- **三态**：每一维只取 3 种离散状态，记为 0 / 1 / 2。
- **19683**：9 个维度各取三态的全部组合数 = 3^9 = 19683。每个情节节点、每个人物状态都对应唯一坐标与唯一编号，编号范围 0–19682。

三元之间允许任一并置，不设优先级；九维互相独立，标注时逐维判定。

## 二、九维定义与三态判据

标注对象：**情节节点**（一次场景或事件切分单位）与**人物状态**（该人物在某节点的处境与能动性）。

### 时间元（T）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| T1 时间流向 | 顺时：严格线性推进 | 回溯：闪回/倒叙介入，主线仍可辨 | 非线性：跳跃、循环、多线并行时间 |
| T2 时间尺度 | 微观：以小时/天计，聚焦瞬间与当下 | 中观：以周/月/年计，情节常规展开 | 宏观：数年/世代/史观时间纵深 |
| T3 时间节律 | 平缓：冲突密度低，渐变推进 | 波动：张弛交替，有明显节拍 | 紧绷：密集爆发、倒计时、高压悬置 |

### 空间元（S）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| S1 空间层级 | 微观：内心、密室、单间等私密/局促尺度 | 中观：城市、组织、舞台等社会尺度 | 宏观：世界、星系、多重世界等全景尺度 |
| S2 空间流动性 | 静止：聚焦单一地点 | 迁移：多地点间移动 | 跨越：世界/维度/虚实之间跃迁 |
| S3 空间结构 | 封闭：孤岛、围墙、密室等强约束 | 半开放：有边界但可探索 | 开放：无边界广域世界 |

### 因果元（C）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| C1 因果归因 | 人物驱动：选择与意愿主导事件 | 环境驱动：局势、他人、意外主导 | 宿命驱动：命运、天意、不可抗力 |
| C2 因果链长 | 短链：因果立现，即时反应 | 中链：伏笔在若干节内回收 | 长链：跨全书/跨世代才闭合 |
| C3 因果封闭 | 开放：留白、未解、续作空间 | 部分闭合：主线闭合、支线开放 | 完满闭合：全部因果闭环 |

## 三、19683 编码公式

维度固定顺序：T1 T2 T3 S1 S2 S3 C1 C2 C3。

以三进制加权求和：

```
code = T1*3^8 + T2*3^7 + T3*3^6
     + S1*3^5 + S2*3^4 + S3*3^3
     + C1*3^2 + C2*3^1 + C3*3^0
```

- 坐标写法：`T1T2T3-S1S2S3-C1C2C3`（如 `020-112-201`）。
- 编号范围：0–19682，恰好 19683 个不同状态，全空间无空位、无重复。

示例：
- `000-000-000` = code 0：顺时、微观、平缓、内心、静止、封闭、人物驱动、短链、开放。最「素」的起点态。
- `222-222-222` = code 19682：非线性、宏观、紧绷、跨世界、开放、宿命、长链、完满闭合。全展开的终局态。

## 四、映射流程（四步）

1. **切分节点**：按场景/事件把文本切成 N 个情节节点（Node_1…Node_N），记录每个节点的在场人物集合与先后关系。
2. **逐维标注**：对每个节点，依上表九维逐一判定 0/1/2，得到九元组坐标；同一节点上，每位主要人物另标一份「人物状态坐标」（侧重其在 T1 流向感知、S3 结构处境、C1 归因能动上的值）。
3. **编码归档**：用公式把每个坐标换算为编号，建立「节点编号 × 坐标 × 原文位置」对照表。
4. **轨迹串联**：按叙事顺序串联节点坐标，得全书的**状态路径**；按人物串联人物坐标，得每位主要人物的**状态轨迹**。

## 五、分析方法（六项，全部由步骤四的产物计算）

1. **维度分布**：九维各自 0/1/2 的频次直方图——看小说整体倾向。
2. **状态路径图**：节点编号随情节推进的变化曲线——看叙事节律与结构起伏。
3. **转移幅度**：相邻节点坐标的逐维差异与编号差——大幅跳变处即转折点/高潮点。
4. **结构指纹**：三元各自的出现重心（众数态）+ 全书熵值 H = -Σp·log p——一句概括「这是怎样一部结构型小说」。
5. **人物轨迹对比**：主角与配角在 C1 归因、T1 流向上的轨迹差异——看成长性与主导性。
6. **关键节点标记**：|Δcode| 最大、或同时改变 ≥3 维的节点，标记为结构性转折点。

## 六、再创作接口

1. 从第六节取出原作的**结构指纹**（三元重心 + 熵值 + 主要转折点坐标）。
2. 确定再创作策略：a) 保留指纹（同构新故事）；b) 镜像翻转（如把 S3 封闭换成开放、C1 人物驱动换成宿命驱动）；c) 变奏（保留主元、变异副元）。
3. 依据策略设计新作的情节节点状态蓝图（每个关键节点给出目标坐标），再围绕坐标写场景、人物与冲突。
4. 成稿后回贴同一坐标系自检：新作是否抵达蓝图坐标、指纹是否符合策略。

## 七、使用边界

- 本框架是**分析坐标系**，不评判文笔与审美；同一坐标下可以诞生完全不同的文本。
- 三态判据以「文本实际呈现」为准，不被作者访谈或外部解读覆盖。
- 存在争议的节点取多数标注一致值，并在报告中注明歧义维度。
