# Mapping Guide — 四步映射 + 六项分析

本指南说明如何把任意小说文本放入三元九维 19683 坐标系并完成全部定量分析。规则细节见 [framework.md](framework.md)。

## 一、四步映射流程

### Step 1 · 切分节点 (Split into nodes)

按场景/事件把文本切成 N 个情节节点 `Node_1 … Node_N`：

- 以"回"、"章"或"场景换场"为天然切分单位的文本直接以章节为节点；
- 无章节文本按"地点/时间/事件"变化切分；
- 记录每个节点的在场人物集合与先后关系。

### Step 2 · 逐维标注 (Annotate 9 dimensions)

对每个节点，依判据表给 9 个维度各取 0/1/2：

| 元 | 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- | --- |
| 时间 T | T1 流向 | 顺时 | 回溯 | 非线性 |
| | T2 尺度 | 微观(小时/天) | 中观(周/月/年) | 宏观(数年/世代) |
| | T3 节律 | 平缓 | 波动 | 紧绷 |
| 空间 S | S1 层级 | 微观(内部/密室) | 中观(城市/组织) | 宏观(世界/多世界) |
| | S2 流动性 | 静止 | 迁移 | 跨越 |
| | S3 结构 | 封闭 | 半开放 | 开放 |
| 因果 C | C1 归因 | 人物驱动 | 环境驱动 | 宿命驱动 |
| | C2 链长 | 短链 | 中链 | 长链 |
| | C3 封闭 | 开放 | 部分闭合 | 完满闭合 |

同一节点上，每位主要人物另标一份**人物状态坐标**（侧重 T1 流向感知、S3 结构处境、C1 归因能动性）。

### Step 3 · 编码归档 (Encode)

维度顺序固定 `T1 T2 T3 S1 S2 S3 C1 C2 C3`，按三进制加权求和：

```
code = T1·3⁸ + T2·3⁷ + T3·3⁶
     + S1·3⁵ + S2·3⁴ + S3·3³
     + C1·3² + C2·3¹ + C3·3⁰
```

建立「节点编号 × 坐标 `T1T2T3-S1S2S3-C1C2C3` × 19683 编码 × 原文位置」对照表。

### Step 4 · 轨迹串联 (Chain trajectories)

- **状态路径**：按叙事顺序串联节点坐标 → 全书结构路径；
- **人物轨迹**：按人物视角串联人物坐标 → 各主要人物轨迹。

## 二、六项分析方法

1. **维度分布**：九维各自 0/1/2 频次直方图 → 整体倾向（如《红楼梦》T1=0 达 115/120）。
2. **状态路径图**：节点编号随情节变化的曲线 → 叙事节律。
3. **转移幅度**：相邻节点逐维差异与编号差，大幅跳变处 = 转折/高潮。
4. **结构指纹**：三元各自重心（众数态）+ 全书熵 `H = -Σp·log₂p` → 一句定调。参考：均匀分布上限 log₂3 ≈ 1.585 bits；《红楼梦》全书熵 1.3929。
5. **人物轨迹对比**：主角与配角在 C1 归因、T1 流向的差异 → 成长性与主导性。
6. **关键节点标记**：|\u0394code| 最大、或同时改变 ≥3 维的节点 = 结构性转折点。

## 四、标注口径提醒

- 判据以「文本实际呈现」为准，不被作者访谈或外部解读覆盖；
- 存在争议的节点取多数标注一致值，并在报告中注明歧义维度；
- 本框架是分析坐标系，不评判文笔与审美。
